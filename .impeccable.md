## Design Context

### Users
Friends and family at a party, 3–12 players. One shared big screen (TV/laptop, read from across the room) plus everyone's phone (quick, one-handed, often tipsy or distracted). The job: write funny answers, vote, laugh together. Sessions are casual and loud.

### Brand Personality
Loud, cheeky, unserious. Three words: **brash, silly, showbiz**. The interface should feel like a cheap, enthusiastic 90s TV game show, never like a polished SaaS product. Emotions: excitement, mischief, competitive fun.

### Aesthetic Direction
- **Direction**: 90s game show. Saturated colors, hard black outlines, offset (non-blurred) drop shadows, starbursts, ticket/sticker shapes, chunky display type (Bungee-style), slightly tilted elements.
- **Theme**: Bright/light base (cream/yellow) with saturated accents (hot pink, electric blue, yellow, black outlines).
- **Scope**: Default theme only. The Lars/clover theme stays as is.
- **Anti-references**: Pastel gradients, frosted glass/backdrop blur, soft blurred shadows, pill buttons with gradients, gradient text, purple-to-blue gradients, anything that reads as generic AI/SaaS output.
- **Accessibility**: Keep text contrast strong (black on bright works well); respect prefers-reduced-motion; big tap targets on phones; large legible type on the host screen.

### Design Principles
1. **Hard edges over soft glow**: thick black borders and solid offset shadows replace blur, glass, and gradients.
2. **Tacky on purpose**: starbursts, tilts, stickers, and loud type are the point, but commit fully and keep them consistent.
3. **Readable from the couch**: host screen type is huge and high-contrast; phone controls are chunky and obvious.
4. **Motion is punchy, not smooth**: quick snaps and wobbles that feel like game-show reveals; always honor reduced motion.
5. **Don't touch the Lars theme**: scope overrides to the default theme so the clover theme keeps its identity.
